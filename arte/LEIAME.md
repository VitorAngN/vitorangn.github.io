# Artes do site

Coloque aqui as imagens com estes nomes. Se um arquivo não existir, o espaço dele some sozinho.

| Arquivo | Onde aparece | Dica |
|---|---|---|
| `topo.png` | Topo, atrás do menu (Projetos/Sobre/Stack/Contato) | PNG **com fundo transparente** (personagem recortado), em pé, uns 900×1200 px |
| `sobre.png` | Embaixo da frase "Morre, aprende, tenta de novo." | Qualquer imagem; é recortada num paralelogramo vermelho. Vertical (4:5) fica melhor |
| `contato.png` | Canto direito do bloco "Bora conversar?" | PNG com fundo transparente, uns 600×800 px |

Para trocar, é só substituir o arquivo com o mesmo nome e dar push.
